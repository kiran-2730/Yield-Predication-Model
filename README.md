An AI-powered Crop Yield Prediction web application built using Flask, Machine Learning, and Python.
This system predicts agricultural crop yield based on environmental and farming parameters such as rainfall, area, fertilizer usage, pesticide usage, crop type, season, and state.

**How to run the file 
**
Create Virtual Environment
python -m venv env

Activate Virtual Environment
Windows
env\Scripts\activate

Install Dependencies
pip install -r requirements.txt

Run the Application
python app.py
